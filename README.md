# Workflow Engine

This project implements a workflow engine that executes a series of steps based on dependencies and predefined functions. It includes testing workflows to validate the engine's behavior.

## Prerequisites

- Node.js (version 14 or higher)

## Running the Script

1. Ensure you have Node.js installed on your system.
2. Open a terminal and navigate to the project directory.
3. Run the following command to execute the script:

   ```bash
   node engine.js
